Where is your Jellyfin server?

Jellyfin is your own server, so there is no address to ship with the app. Give it the one you would type into a browser — StreamHub loads the web player from there and keeps you signed in to it like any other service.

  • On your own network it is usually http://<ip>:8096 — the same address the Jellyfin app on your phone or TV uses.
  • A path is fine (https://media.example.com/jellyfin), and anything the browser added after it is trimmed for you.
  • HTTPS with a self-signed certificate will not load — over the local network use plain http, or give the server a real certificate.
  • Getting it wrong costs nothing: right-click Jellyfin in the sidebar to change it.
