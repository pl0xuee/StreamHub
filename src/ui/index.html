      YouTube

      Scroll down as usual to reach the description and comments. Turn this off if YouTube changes its layout and the page starts looking wrong.

      Twitch

      This is Twitch's own theater mode, switched on for you. Leaving it on one stream lasts until you open the next; turn this off to be left where Twitch puts you.

      Sidebar

      Turn hiding off to keep the sidebar out permanently. Either way nothing behind it moves or resizes — only the sidebar travels, so the page you are watching stays exactly where it is.

      Display

      Auto asks the desktop what scale the monitor is set to and follows the window from one monitor to the next. Pick a fixed size if the desktop cannot say, or if you would rather have the app larger or smaller than it thinks.

      Playback

      If a video ever comes out green, black or torn, turn the graphics-card decoding off and restart — that is a driver getting it wrong, and the processor can always do it.
